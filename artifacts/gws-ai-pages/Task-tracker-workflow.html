How a task moves from the app to Google Tasks and the daily report

Everyone works in one AppSheet app. Every task and every progress update is a row in one Google Sheet. A script running as each person copies their open tasks to their Google Tasks every 5 minutes, and emails them a draft Daily Work Report (DWR) each working evening.

A task's life, end to end

  1. Someone adds a task in the app. It is saved as a row in the Tasks tab, and the app places it in a quadrant from its Important and Urgent answers. A target date 2 working days away or less counts as urgent.
  2. If it is assigned to someone else, the Tell assignee bot emails them a link to the task.
  3. Within 5 minutes, syncTasks copies it into the assignee's Google Tasks list Eisenhower, titled like [Q1] Fix OEE dashboard.
  4. Through the day, the assignee logs progress with Add update. Each update is a row in the Updates tab, and any new status (In Progress, Blocked, Done) is applied to the task as soon as the form is saved.
  5. To finish, they tap Done in the app, or tick the task off in Google Tasks; syncTasks then marks it Done in the Sheet within 5 minutes.
  6. Between 6 and 7 pm on working days, sendMyDailyReport emails each person their DWR, built from today's updates and completed tasks. They add context and forward it to the manager.

If something goes wrong

  • Ticked in Google Tasks, still open in the app: wait up to 5 minutes, then tap sync in the app.
  • Someone's Google Tasks stopped updating: they run setup() again. It rebuilds both of their scheduled jobs.
  • No DWR: it is not sent on weekends, on dates in the Holidays tab, or when nothing was logged that day. Check Spam, then Executions in the script editor.
  • Task deleted in Google Tasks: it stays deleted there (Sync marks it DELETED) and stays open in the app. Close it in the app.
  • Problem details: script runs are in Apps Script → Executions; bot runs are in AppSheet → Automation → Monitor.
  • Never edit the Sheet directly, except to add people in the Users tab. The Sync tab is written only by the script.
